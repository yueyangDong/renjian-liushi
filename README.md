## 三条核心规则

**一、六事取 min，不求和；而且这六样你看不见。**
一岁十二个月令，每件事都要占格。所有"无法兼得"最终都能还原成"今年这十二格，你给了谁"。结算不看你赢了多少，只看你最薄的那一块。

左栏六行只有虚线——**数字、彩条一概没有**，加减只报 ↑/↓。只有**任意一格推到了你的顶**（上限，或 100），才会「透」：六事俱明，全盘亮起。看清自己的唯一方式，是把一件事做到没人能装作没看见。

而"顶"不是人人一样高：**官宦人家的禄顶 80，罪臣之后 30；市井无禄的人，这一格压根不存在。** 官宦三十九岁做到他父亲那一级的那天，也就是他的「透」。没有位子的人不按禄结算——他不是缺了那一格，是没有那一格。

**二、五世同一个八字，古或今不由你挑。**
八字在开局前**由你自己填生辰排出**（年柱以立春分界、月柱以节气分界、日柱按儒略日直推，可填 1900—2026），跨局锁定——不随出身、时代、职业改变。不想填也可以让系统随便给一副。变的只有壳：生在哪家、生在哪年、你选了哪条路。古代窗口取**嘉靖前后各五十年（1494—1594）**，以嘉靖五年（1526，丙戌）为卷首之年；现代取"现在"（2020—2032）。每局独立掷，但**五局古今各不少于二**。

**生在哪家，也不是你挑的。** 十二种出身随机一张牌，揭开来是什么就是什么——能挑，就会退化成难度选择，而"这局抽到了罪臣之后"才是它该给你的东西。

**三、第一世看不见自己。**
六才（智、体、言、巧、忍、缘）永不以数字示人。你只能从"事办得顺不顺"里反推，而反推出来的印象记在**手记**里——**手记可能是错的**。第五世结算，命书才开。

## 原型范围

**已实现**：八字排盘（年柱以立春分界、月柱以节气分界、日柱按儒略日直推、时柱五鼠遁）、六才隐藏成长、**六事五档（极薄／薄／够用／厚／极厚，只给字不给数）与「透」（一格到了你的顶才改看真数）**、五局随机古今、六事与月令、**六十六条事件（正文／标题／选项／小注／手记皆有古今两套，每条三到四个选项、各一记手记）＋ 六类生成式事件（树大／对质／独坐／账簿／退还／深水）**、**子的五级台阶（有后/立业/有孙/家和/四世同堂）、誉的一极即满与方外之路、律的暗线（问拟/立案、首告、出家、深水四门与退还三条）**、三关、手记（含"错误的记忆"）、命书、天机、改史与跨世已知、**三记音效（掷局/透/卒，WebAudio 现场合成，右下角可关）**、单机存档。

**气运与学**（§1.6–1.7）：六事之外还有一手看不见的「运」——由八字的合冲定底，三折一大转，转的时候只报一句"风向变了"。它决定过三关、得子、战和、情关的成与败；顺的时候名声涨得快，背的时候做什么都差一口气。左栏只给一句口气，不报数。「学」则能**把你的顶往上撑**（最多 12 格、封顶 90）——读书改得了命，但改不到极处，95 那一格只属于命里带来的。

**透一次，根就留下了**（§1.5）：五世里只要有一世看清过自己一次，此后各局起卷时 hub 会多出「看 根 · 命 书」——四柱与六才随时能翻。第一次什么也看不见；看过一次，就再忘不掉。

**结局分八层**（§1.8）：覆／六全／孤／绝／寻常／**起伏**／缺一／空。「寻常」只占 6%，「起伏」占三成半——同样是最薄一格低，"其余五格都到了 80"和"五格全塌"不是一回事，得分开说。

**无禄之家也有"儿子出息"的路**（§1.9）：市井十二行没有位子，原本的儿子永远"未成器"，「子」卡在 45。现在改看「誉」——街坊认你这块招牌，儿子才立得起来；而且不是一锤子买卖，儿子十六岁之后年年看，誉到了就算。立业率：商 39%／仕 30%／市 23%（回归台 2000 局实测）。这两个数字比早先的 51/28/26 低，是因为「有后」接回了「室」：**室薄的人晚得子，很多人等不到儿子二十岁那一年**——立业那一判根本没发生。这是设定里那句话的数字形态，不是缺陷。

**这一版新接的三套机制**（此前只在设定里）：

- **职业三条轴 + 市井十二行**（§4）。十八个行当各有自己的每折流量：文官升得快而家里空，军职命是国家的，商人的财是攒出来的，市井的人只有一双手和每天少一点的力气。禄 = 组织授予的位置，**无禄的人财与誉上限各 +10**，代价是任何一件官面上的事都没有"位"可挡。
- **六轨**（§5）。不是转职，是**被归位**：你在事上选边的痕跡被归一化后比较（替人办事的机会到处都是，独奏独行的机会很少，所以机会多寡要折算掉）。**每条轨都缺一项**——清流缺禄、能吏缺清誉、权臣缺寿与室、边臣缺寿与室、循吏缺禄、孤臣缺室。改轨一次誉 −8；孤臣要先"无室"或"断党"。
- **史评五笔法 + 情关四种**（§5.5、§7）。本传／附传／循吏·酷吏传／佞幸传／无传，按轨与墨定；**「门生」到死后才结算**——你活着时不肯提携后进，死后就没有人替你说话。**史评本身也分古今**：古世写《佞幸传》《循吏传》，今世写讣告底下的评论、内部通报、地方志里那一行（见下）。情关有 A/B/C/D 四种、三轴（情／义／时），**情不出数字**，你只能从回信的字数里猜；窗口过期作废，每种关都会锁掉六事里的一项上限 70。

**古 / 今两套文案**（§10.4）：公元前的朝代没有"当代"，所以这不是复刻而是**对位**。哪些必须换口、哪些刻意共用，有一条硬标准——**制度的名字必须换，人的处境不必换**：

| 层 | 古 | 今 |
|---|---|---|
| 选项 | 留馆 · 外放 · 再等一科 | 留总部 · 下去带项目 · 再等一年 |
| 小注 | 衙门的规矩 | 这一行的规矩 |
| 手记 | 签契的时候，我爹的牌位还在堂上 | 过户那天，我爹的遗像还挂在墙上 |
| 出身 | 父亲的功名未竟 | 父亲的学没上完 |
| 轨名 | 清流 · 能吏 · 权臣 · 边臣 · 循吏 · 孤臣 | 笔杆子 · 干将 · 实权派 · 外派 · 主事 · 独行 |
| 史评 | 《佞幸传》《循吏传》· 本传 · 附传 | 讣告底下的评论 · 内部通报 · 地方志里有一行 · 词条 · 档案里只有一张表 |

**史评是整本换掉的**：古世有史官替你留名，今世只有四样东西——档案、通报、词条、评论区。分寸一样（都是"别人怎么记你"），载体不一样。而六事名、八层判词、情关正文、数目与代价刻意共用：那是量纲与共同处境，不分古今。

**覆盖是逐条核过的**：六十三条事件里，除"庚戌之变"（只有古世）外，一百八十五个选项的今世说法全部落地，另有同榜／满招损／对质／账簿四类生成式事件十三个选项。做法不是散在各处写 `tMo`，而是**一张独立的映射表 `MO_OPT`**，开局时补进事件表——表里没有的字段才回落到古世文案，改起来一处改、查起来一处查。校验也用得上：一张古语词表扫今世那一面（衙门／俸／折子／保举……），一张现代词表扫古世那一面（微信／项目／考核……），两边都不许漏。

**这一版新接的四套机制**（此前只在设定里，或在设定里也没有）：

- **同榜三人 + 党争网**（§5.8）。开局生成三个跟你同一年进门的人，各有自己的位置，每折自己往上走。四类事：**求你、挡你、倒了、还账**——一局平均撞上 2.6 次。帮过他，一折后他来还；划清界限或踩一脚，就留下"凉薄"两个字，也留下一个记得你的人。三人里必有一个**从不犯错、也从不被记住**的人，他不制造事件，只制造对照。结局页多一行，三个人的下落并排写着。
- **满招损**（§1.10）。一样做到极处，别处就开始漏：某一格 ≥92 时，每折 35% 让随机另一项 −2（没有提示，只在手记里偶尔落一句）；某一格 ≥88 时，还会有人递折子——**树大**。三条路：收（该项 −10、换誉与寿）、扛（该项 +4，代价落在别处 −12）、让名（誉 −8、禄 +6、财 +4）。**六全之所以难，不是六项够不着，是六项不能同时停在 90 以上。**
- **两段关系对质局**（§7.6）。第二段关系从两个地方来：纳妾，或 28 岁后遇到旧人（`again`）。出现之后，**下一折必到对质**——不是概率，是账。认（誉 −10、室 −14）／瞒（财 −10、寿 −6，并把誉的上限锁到 70）／断一头（财 −14、誉 −4）。三种收场都会在结局的「情」那一行留下一个字：负／疑。19.5% 的局会走到这一步。
- **事后账簿三年回响**（§8.5）。一折四年，所以"三年后"就是**下一折**。一次选择里禄／誉／财绝对值之和 ≥16 的，算大账，登记在案，下一折必有人来翻：**旧账**（带墨的签字被翻出来）、**旧怨**（被你压过的人回来了）、**旧恩**（你放过的人如今能替你说一句）。每局平均一笔。

## 设计上两处被原型推翻的规则

1. **寿不参与 min**。寿归 0 就是死，不是"缺寿"；若把 0 算进 min，每个结局都是"空"。
2. **天机不是"必须 95"**。按八字规则能出现 95 的命只占 9%，改成"**摸到自己的顶**（上限 ≥78）"，才不是抽奖；95 那一格只多一行朱批。
